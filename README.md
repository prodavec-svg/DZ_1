# ДЗ 1

## Источник данных

[Steel Plates Faults](https://www.kaggle.com/datasets/eouedraogo4/steel-plates-faults) - первый датасет из списка задания.

## Гипотезы

1. Масштабирование признаков повысит F1-macro логистической регрессии, поскольку признаки имеют разные масштабы.

2. Случайный лес покажет более высокий F1-macro, чем логистическая регрессия, благодаря учёту нелинейных зависимостей и взаимодействий признаков.

3. Дерево без ограничения глубины переобучится сильнее дерева с глубиной 10: F1-macro на обучении будет выше, а на валидации — ниже.

4. Удаление сильно коррелирующих признаков сохранит качество логистической регрессии: снижение среднего F1-macro составит не более 0.01.

5. Отбор 10 признаков через `SelectKBest(f_classif)` сохранит качество логистической регрессии: снижение среднего F1-macro составит не более 0.01.

6. У логистической регрессии без балансировки классов accuracy превысит F1-macro как минимум на 0.05 из-за неодинакового качества на частых и редких классах.

## Результаты

Лучшая модель — случайный лес. На тесте: **F1-macro - 0.803**, **accuracy - 0.797**.

Гипотеза 1 подтвердилась; гипотезы 2 и 3 - частично; гипотезы 4–6 не подтвердились.
